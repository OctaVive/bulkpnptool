Vodafone Bulk PNP Provisioning

CSV file genrator for VOF NGIN.

Provisioning-safe · PE lookup from file
One number or number block per line. Wildcards like 45568820X are supported and are not expanded in the CSV.

How it works

  • Input formats — Accepts 455688200, 0455688200, +31455688200, and wildcard blocks like 45568820X.
  • PE codes — Resolved from data/pe_codes.txt using 4-digit then 3-digit Dutch prefixes.
  • 050 / 0521 / 0522 / 0524 / 0527 / 0598 / 0599 numbers — Never auto-resolved; a location selector is shown using the corresponding data/*_locations.txt files.
  • Wildcard blocks — Used for PE lookup only (with X→0), but exported exactly as entered.
  • CSV format — RowNumber;Operation;PhoneNumber;PE Code;PBX-ID with 9‑digit phone numbers for non-wildcards.
